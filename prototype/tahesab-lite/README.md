# ته‌حساب لایت

نمونهٔ اولیهٔ هستهٔ مشترک وب/دسکتاپ برای حسابداری طلا و جواهر.

فایل `index.html` را با مرورگر باز کنید. امکانات فعلی: داشبورد، کالا و موجودی، طرف‌حساب‌ها، خرید، فروش، گزارش‌های پایه، اعتبارسنجی فیلدها، حذف رکورد، پشتیبان‌گیری و بازیابی JSON محلی.

این نسخه نمونهٔ اولیه است و برای استفادهٔ واقعی هنوز به پایگاه‌دادهٔ چندکاربره، احراز هویت، محاسبات طلا/اجرت/سود، همگام‌سازی و بسته‌بندی ویندوزی نیاز دارد. بررسی عامل‌های کمکی نیز نشان داد که قبل از استفادهٔ واقعی باید منطق فاکتور و گردش موجودی، مدل دادهٔ نسخه‌بندی‌شده و امنیت چندکاربره اضافه شود.

## لایهٔ Convex

پوشهٔ `convex/` مدل داده و API اولیهٔ کالا و تراکنش را دارد. برای فعال‌سازی پس از نصب Node.js اجرا کنید:

```bash
npm install
npx convex dev
```

رابط فعلی بدون اتصال هم کار می‌کند؛ اتصال reactive فرانت‌اند به توابع Convex مرحلهٔ بعدی است.
